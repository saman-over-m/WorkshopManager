# Factor Plus — نسخه وب آفلاین

## اصلاحات این نسخه
- پیش‌نمایش PDF واقعی داخل پنجره برنامه؛ دکمه «چاپ» جداست و PDF دیگر مستقیماً چاپ را باز نمی‌کند.
- ساخت PDF سمت مرورگر با فایل PDF معتبر و قابل نمایش در مرورگرهای دسکتاپ.
- پیش‌نمایش PNG/SVG به‌صورت واکنش‌گرا و بدون اسکرول افقی؛ تصویر کامل داخل پنجره جا می‌شود.
- کش Service Worker به نسخه جدید ارتقا داده شده تا فایل‌های اصلاح‌شده جایگزین نسخه قبلی شوند.

## اجرای نسخه وب
فایل `index.html` را با Chrome یا Edge باز کنید. برای استفاده از ذخیره مستقیم در پوشه ویندوز، Chrome/Edge مناسب‌تر است.

اگر نسخه قدیمی نمایش داده شد، یک بار مرورگر را Refresh کنید و در صورت نیاز کش سایت/Service Worker را پاک کنید.
