# Factor Plus V30 — اصلاح شکستن متن در تصویر/PDF

- شرح کالا/خدمت در خروجی SVG/PNG/PDF اکنون به چند خط شکسته می‌شود.
- ارتفاع ردیف بر اساس تعداد خطوط متن بلند افزایش پیدا می‌کند تا متن روی ردیف بعدی نیفتد.
- برای سازگاری بهتر خروجی SVG، `xlink:href` نیز برای لوگو اضافه شده است.
- ظاهر پیش‌نمایش صفحه تغییر داده نشده است.
- `app.js` با `node --check` بررسی شد.
