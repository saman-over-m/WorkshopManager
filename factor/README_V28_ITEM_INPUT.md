# Factor Plus V28 — ورود سریع کالا و قیمت کل

- دکمه «افزودن مورد جدید» دیگر sticky نیست و روی ردیف آخر نمی‌افتد.
- با زدن Enter داخل «قیمت واحد / قیمت کل»، یک ردیف جدید ساخته می‌شود و فوکوس روی شرح ردیف جدید می‌رود.
- کنار قیمت هر ردیف یک تیک کوچک «کل» اضافه شده است.
- اگر «کل» فعال باشد، مبلغ واردشده قیمت کل همان ردیف است و قیمت واحد به‌صورت خودکار از مبلغ کل ÷ تعداد محاسبه می‌شود. با تغییر تعداد نیز قیمت واحد خودکار به‌روز می‌شود.
- برای فاکتورهای قدیمی، ساختار قبلی بدون نیاز به ورود دوباره اطلاعات قابل استفاده است.
