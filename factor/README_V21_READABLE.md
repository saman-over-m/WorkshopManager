# Factor Plus V21 — پیش‌نمایش خوانا

بر پایه منطق خروجی تست‌شده V20/V13. فقط اندازه نمایش پیش‌نمایش اصلاح شده است.

- تصویر به‌صورت پیش‌فرض با عرض خوانا (تا 794px برای A4) نمایش داده می‌شود.
- در صورت نیاز فقط اسکرول عمودی داخل پنجره وجود دارد.
- PDF داخل پنجره بزرگ‌تر نمایش داده می‌شود و حالت page-fit دارد.
- منطق تولید تصویر/PDF و چیدمان فاکتور تغییر نکرده است.
