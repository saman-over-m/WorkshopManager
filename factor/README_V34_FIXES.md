# Factor Plus V34

این نسخه دو مشکل واقعی V33 را اصلاح می‌کند:

1. **باز نشدن فاکتورهای ذخیره‌شده**
   - در V33 تابع `syncAccentPicker` به اشتباه داخل `bind()` تعریف شده بود، اما `loadInvoice()` قبل/خارج از آن به این تابع نیاز داشت؛ در نتیجه Chrome خطای `ReferenceError: syncAccentPicker is not defined` می‌داد.
   - در V34 تابع به سطح اصلی برنامه منتقل شده و `loadInvoice()` می‌تواند فاکتور را کامل بارگذاری کند.

2. **بریده شدن پایین تصویر فاکتور بلند**
   - V33 دو تابع با نام `buildExportImages` داشت. تابع دوم، تابع اولِ دارای حالت `longImage` را بازنویسی می‌کرد؛ بنابراین اصلاح ارتفاع تصویر عملاً اجرا نمی‌شد.
   - در V34 فقط نسخه `longImage` باقی مانده است.
   - PNG از ارتفاع واقعی SVG استفاده می‌کند و صفحات را در صورت وجود، عمودی به هم متصل می‌کند.

تست‌های استاتیک:
- `node --check app.js` موفق.
- `unzip -t` روی ZIP موفق.
- `syncAccentPicker` فقط یک بار و خارج از `bind()` تعریف شده است.
- `buildExportImages` فقط یک بار تعریف شده است.
