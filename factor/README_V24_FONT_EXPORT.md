# Factor Plus V24 — فونت در خروجی تصویر/PDF

## رفع مشکل
- فونت انتخاب‌شده دیگر فقط در پیش‌نمایش HTML اعمال نمی‌شود؛ هنگام ساخت SVG خروجی، همان font-family در خروجی استفاده می‌شود.
- فونت سفارشی آپلودشده داخل SVG خروجی embed می‌شود تا PNG و PDF همان فونت را داشته باشند.
- قبل از خروجی، برنامه منتظر آماده‌شدن فونت مرورگر می‌ماند.
- Vazir، Lalezar و Dirooz در لیست فونت‌ها اضافه شده‌اند و در اولین انتخاب از منبع عمومی بارگیری و در localStorage ذخیره می‌شوند تا دفعات بعد حتی آفلاین قابل استفاده باشند.
- IRANSans و B Ziba در لیست هستند، اما فایل آنها به دلیل مجوز توزیع داخل ZIP قرار داده نشده؛ اگر فایل TTF/OTF دارای مجوز خودتان را آپلود کنید، همان فایل در پیش‌نمایش و خروجی embed می‌شود.

## نکته
برای استفاده اولیه از Vazir/Lalezar/Dirooz نیاز به اینترنت است؛ پس از یک بار بارگیری و ذخیره، برنامه می‌تواند از نسخه cache شده استفاده کند.
