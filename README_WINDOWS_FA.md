# Workshop Manager — مسیر تبدیل v16 به Windows

این پوشه بر پایه **Workshop Manager Web v16** ساخته شده است.

## نکته مهم
اول در GitHub Actions فقط تست اجرا می‌شود؛ اگر تست‌ها سبز شدند، در مرحله دوم EXE ساخته می‌شود. بنابراین لازم نیست هر بار برای یک خطای ساده منتظر ساخت EXE بمانید.

## داده‌ها و دیتابیس
نسخه Windows یک دیتابیس واقعی SQLite دارد:

`%APPDATA%\Workshop Manager\Data\workshop.sqlite`

اطلاعات اصلی Workshop Manager در SQLite ذخیره می‌شود و در هر ذخیره تغییرات روی دیسک flush می‌شود.

## پوشه بکاپ
بکاپ‌های قابل مشاهده کاربر در:

`Documents\Workshop Manager Backups`

ذخیره می‌شوند.

دو زمان‌بندی در نظر گرفته شده:
- هر روز ساعت 23:55
- پنجشنبه ساعت 17:00 به‌عنوان بکاپ اضافه هفتگی

در نصب EXE، Task Scheduler ویندوز به‌صورت خودکار دو وظیفه می‌سازد؛ بنابراین بکاپ حتی وقتی برنامه بسته است هم انجام می‌شود. با حذف برنامه نیز این دو Task حذف می‌شوند.

## روش پیشنهادی GitHub
1. این پروژه را در یک Repository خصوصی GitHub قرار دهید.
2. ابتدا Push کنید.
3. GitHub Actions در `windows-check.yml` تست Syntax و Smoke Test را اجرا می‌کند.
4. اگر سبز شد، Workflow ساخت EXE را دستی از تب Actions اجرا کنید.
5. فایل EXE/Setup در Artifacts قرار می‌گیرد.

## تست قبل از EXE
تست Electron با Playwright برنامه را واقعاً باز می‌کند و وجود خطاهای JavaScript/Renderer را بررسی می‌کند.

## فعلاً چه چیزی عمداً تغییر نکرده؟
قابلیت ویس v17-v22 در این شاخه وارد نشده است. پایه این نسخه **v16** است، مطابق درخواست پروژه.
